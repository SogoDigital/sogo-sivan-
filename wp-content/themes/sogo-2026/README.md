# Sogo 2026 – ערכת נושא

ערכת הנושא החדשה של סוגו. עיצוב נקי עם נקודות צבע מהלוגו, אנימציות גלילה (GSAP + ScrollTrigger), גלילה חלקה (Lenis), ועריכה בעברית דרך שדות ACF.

## הפעלה
1. ודאו שהתוסף **Advanced Custom Fields PRO** פעיל.
2. בלוח הבקרה: **מראה ← ערכות נושא ← Sogo 2026 ← הפעלה**.
3. בתפריט הצד תופיע האפשרות **הגדרות האתר** (כפתור הכותרת, פרטי קשר, רשתות חברתיות, תחתית).
4. ערכו את **דף הבית** (עמוד שמוגדר כעמוד הבית) כדי למלא את אזור הפתיחה, המשפט הגדול, השירותים והלקוחות.

אפשר לחזור לערכה הישנה בכל רגע דרך **מראה ← ערכות נושא**.

## עריכה בלוח הבקרה (בלי קוד)
כל טקסט, כותרת, כפתור, תמונה, וידאו, טלפון ואימייל נערכים מלוח הבקרה:
- **דף הבית** (עריכת העמוד): לשוניות עליונות. *אזור פתיחה* (סליידר של וידאו או תמונה, בטבלה), *אודות*, *שירותים* (תמונה, שם וקישור לכל כרטיס), *לקוחות*, *שאלות נפוצות*, *תוכן חופשי*.
- **הגדרות האתר** (תפריט הצד): כפתור הכותרת, טלפון, אימייל, תחתית, רשתות חברתיות, וכל הטקסטים הקטנים (זכויות יוצרים, 404, בלוג ועוד).
- **מראה ← תפריטים**: התפריט הראשי ותפריט התחתית.

## מבנה
| קובץ | תפקיד |
|---|---|
| `front-page.php` | דף הבית (פתיחה, אודות, שירותים, לקוחות) |
| `header.php`, `footer.php` | כותרת צפה, תפריט מסך מלא, תחתית |
| `inc/acf-fields.php` | כל שדות העריכה בעברית (נשמרים ב-git) |
| `assets/css/main.css` | כל העיצוב |
| `assets/js/main.js` | האנימציות |
| `assets/vendor/` | GSAP 3.13 (רישיון no-charge של GSAP), Lenis 1.3.25 (MIT) |
| `assets/fonts/` | Rubik (SIL OFL), מאוחסן מקומית |
| `assets/img/` | לוגו סטטי ולוגו מונפש |

## הערות
- ערכי ברירת מחדל מוגדרים בתבניות, כך שהאתר נראה תקין גם לפני מילוי השדות.
- בהעדפת "פחות תנועה" במכשיר, הדף מוצג ללא אנימציות.
- תוכן קיים מהערכה הישנה (`sogo-child`) טרם הועבר לשדות החדשים.
